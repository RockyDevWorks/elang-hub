# ELANG Hub

ELANG Hub is the companion application for exploring validated `.elang` language packages.

## v0.1.0 — Phoneme Viewer

The first release accepts an ELANG v0.1.0 `.elang` package, runs the ELANG SDK's `inspect`, `verify`, and `validate` stages, and renders a read-only Phonemes Page using the validated phonological definitions.

v0.1.0 does **not** include user accounts, persistent publication, language discovery, social features, or leaderboards. Those remain planned for incremental releases through Hub v1.0.0.

## Development
